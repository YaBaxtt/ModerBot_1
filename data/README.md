# Вопросы проверки новичков

Редактируйте `verification_questions.json` в UTF-8. После изменения перезапустите бота.

Каждый вопрос содержит:

- `key`: уникальное постоянное имя латинскими буквами, цифрами и подчёркиванием (до 32 символов);
- `text`: вопрос (до 500 символов);
- `options`: ровно четыре непустых разных ответа (каждый до 80 символов);
- `correct_index`: номер правильного ответа, считая с нуля: 0, 1, 2 или 3.

Кнопки показываются в случайном порядке, по две в строке. Номер ответа относится к порядку в JSON, не на экране.

Добавляйте новые вопросы, не меняя ключи и ответы существующих, пока кто-то проходит минутную проверку. Не удаляйте вопросы незавершённых проверок. Неправильный JSON или повторяющиеся ключи остановят запуск с понятной ошибкой.
