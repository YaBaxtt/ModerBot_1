# Вопросы проверки новичков

Файл с заготовленными вопросами больше не используется. Бот автоматически
создаёт примеры на сложение с результатом не больше 50.

Владелец бота управляет источниками заданий без перезапуска:

1. `/admin` → «🧠 Капча»;
2. включить или выключить автоматические примеры;
3. добавить собственный вопрос, четыре разных ответа и выбрать правильный;
4. просмотреть или удалить собственные вопросы.

Хотя бы один источник заданий всегда должен оставаться активным. Поэтому бот
не даст выключить генератор при пустом списке собственных вопросов и не даст
удалить последний вопрос, если генератор выключен.
