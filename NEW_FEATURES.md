# Обновление: меню, жалобы и объявления

## Управление функциями

`/admin` → «🧩 Функции» содержит 13 постоянных глобальных переключателей. ✅ означает, что возможность работает, ❌ — что новые действия блокируются. Состояние хранится в базе и не сбрасывается после перезапуска.

Можно отдельно управлять проверкой новичков, антиспамом, командами модерации, удалением `/команд`, отслеживанием профилей, начислением очков, рейтингом, ежедневной наградой, магазином, жалобами, рекламой, рассылками и объявлениями. При отключении проверки ожидающие новички освобождаются. При отключении рассылок запланированные задания ставятся на паузу и восстанавливаются после включения. Уже созданные жалобы и покупки остаются доступны владельцу для обработки.

## Изменения профиля участника

Переключатель «Изменения профиля» следит за именем, username и аватаркой отдельно в каждом подключённом чате. Первое действие участника создаёт базовый снимок молча. Если профиль поменялся, уведомление появится при следующем сообщении, команде, нажатии групповой кнопки или событии членства, которое Telegram передаст боту. Username выводится обычным моноширинным текстом и никого не отмечает; имя открывает профиль по Telegram ID даже без username.

У Bot API нет отдельного события «профиль изменён», поэтому бот не может узнать об изменении мгновенно, пока пользователь никак не проявится в чате. Аватар проверяется на активности участника не чаще одного раза в 30 секунд, чтобы не создавать лишнюю нагрузку на Telegram. После повторного включения функции текущие профили запоминаются заново молча — так старые изменения не выдаются за новые.

Отключённые пользовательские разделы отмечаются в меню значком ⛔. Если выключены очки, сообщения продолжают считаться, но новые очки не начисляются; ежедневная награда также становится недоступна.

## Ежедневная награда

Кнопка «🎁 Ежедневный бонус» и команда `/daily` выдают награду один раз в календарный день. Последовательные дни образуют серию и увеличивают бонус до седьмого дня. Повторное нажатие безопасно и не создаёт повторного начисления.

## Статистика и профиль

Статистика владельца разделена на сообщество, показатели за сегодня, задачи и график сообщений за семь дней. «🚨 Центр внимания» собирает открытые жалобы, рекламные заявки, покупки, рассылки и ожидающие проверки.

Профиль показывает оформление блоками, прогресс до следующего уровня, корректное место именно в текущем чате, серию ежедневных наград и предупреждения текущего чата.

## Главное меню

- «➕ Добавить меня в группу» открывает стандартный выбор Telegram. После добавления боту нужно выдать права администратора.
- «⚙️ Настройки группы» показывает только подключённые группы, где нажавший пользователь является администратором, и проверяет права бота на удаление, ограничения и закрепление.
- «🛡 Модераторская» открывает только группы, созданные пользователем, и группы, где его явно назначили доверенным модератором. Центральная «👑 Супер-админка» доступна исключительно ID из `OWNER_IDS`.
- «👥 Группа» и «📣 Канал» настраиваются владельцем прямо в `/admin` → «🔗 Ссылки меню». Значения из `.env` остаются запасным вариантом.
- «ℹ️ Информация» коротко объясняет назначение и возможности бота.

## Владельцы групп и доверенные модераторы

Создатель Telegram-группы открывает «🛡 Модераторская», выбирает только собственную группу и назначает доверенных людей. Кандидата можно выбрать из последних известных участников, указать через `@username`, Telegram ID, ссылку `t.me/username` или переслать его сообщение без скрытого автора. Bot API не предоставляет полный список подписчиков, поэтому бот показывает только участников, которых уже видел.

Обычный Telegram-администратор без назначения не получает команды бота. Модерацию могут выполнять только ID из `OWNER_IDS`, создатель конкретной группы и активные доверенные модераторы этой группы. Назначение не переносится между группами и перестаёт работать, если пользователь покинул группу. Создатель может отозвать доступ в любой момент.

Каждый результат модерации содержит кликабельное имя, username и Telegram ID участника, а также модератора, причину и срок, когда они применимы. Третий активный варн всегда приводит к настоящему бану: участник удаляется из группы и не сможет вернуться до команды `/unban`. Автоантиспам также показывает, кого, на какой срок и за какое повторение он замьютил.

## Пожизненный PRO для группы

Создатель группы может купить PRO один раз через официальный счёт Telegram Stars (`XTR`). Цена задаётся переменной `PREMIUM_PRICE_STARS` и по умолчанию равна 50 звёздам. Доступ закрепляется за выбранной группой навсегда; владельцы из `OWNER_IDS` получают его бесплатно. Покупка выдаётся только после события `successful_payment`, ID транзакции сохраняется от повторной обработки, а случайный повторный платёж бот пытается автоматически вернуть.

В первый рабочий набор PRO входят медиа-фильтр, пользовательский список запрещённых слов, фильтр 18+, защита от четырёх входов за две секунды, блокировка добавляемых ботов и удаление сообщений от имени чужих каналов. Все модули включаются отдельно в настройках конкретной группы.

## Обязательная подписка и рекламные ссылки

Владелец бота настраивает общие ссылки через `/admin` → «📢 Обязательная подписка». Создатель группы настраивает независимый список через «⚙️ Настройки группы» → нужная группа → «📢 Обязательная подписка / реклама». Для каждой ссылки задаются Telegram-канал или чат и короткое описание.

Перед сохранением бот проверяет ссылку и собственные права администратора. В личке неподписанный пользователь видит экран допуска вместо меню. В группе его сообщение удаляется, после чего появляется персональная карточка со ссылками и кнопкой проверки. Администраторы группы и владельцы бота не блокируются.

По каждой ссылке сохраняются показы требования, уникальные пользователи, проверки, подтверждённые подписки и конверсия. Telegram не передаёт обычным ботам факт нажатия URL-кнопки, поэтому вымышленных «кликов» в статистике нет.

Карточка модератора содержит кликабельное имя, username, Telegram ID, дату назначения, назначившего владельца, количество банов, мутов и варнов, а также последние пять действий с причинами и кликабельными целевыми пользователями.

## Навигация

Личные интерактивные экраны автоматически получают «⬅️ В меню», включая промежуточные шаги и завершённую рекламную заявку. Возврат сбрасывает незавершённую форму. Кнопки добавляются только в текущем личном диалоге, не к содержимому фоновых рассылок и не в групповые сообщения. В групповом чате личное меню не показывается.

## Жалобы

- В личке: `/report @username` или «🚨 Пожаловаться». Далее описание, необязательные фото/видео (до 10), подтверждение. Можно отправить альбом.
- На шаге доказательств `/cancel`, `cancel` и кнопка «Пропустить» завершают прикрепление и открывают подтверждение; уже прикреплённые файлы сохраняются. «В меню» отменяет всю незавершённую жалобу.
- Во всех жалобах владельцам показываются кликабельное имя отправителя, username (если есть) и Telegram ID. Ссылка на имени использует ID и поэтому работает без username. Фото/видео отправляются заново по file_id, а не пересылаются. Один файл получает текст жалобы в подписи; несколько файлов приходят единым альбомом с текстом на первом материале и отдельной кнопкой обработки, поскольку Telegram не поддерживает inline-кнопки на медиагруппе.
- Идентификатор отправителя сохраняется в базе для обратной связи.
- `/admin` → «🚨 Личные жалобы»: открытые обращения и сохранённые материалы. Статус «рассмотрено/закрыто» отправляется автору; автоматического бана по жалобе нет.
- В группе `/report причина` отправляется ответом на сообщение нарушителя. Бот первым действием удаляет команду и отвечает персонально. Нужны права удаления. Обычная команда может быть видна до удаления — для большей приватности используйте личку.
- Жалобы на владельцев бота и администраторов подключённых групп блокируются.

Все сообщения, начинающиеся со `/`, удаляются ботом из групп перед обработкой, если у него есть право удаления. Ответы бота остаются видимыми.

## Новички

После успешного теста бот снимает ограничение, отправляет приветствие только участнику и удаляет общий вопрос. Если Telegram отклоняет персональное сообщение в группе, бот пробует личку, но не публикует приветствие для всех. Telegram не гарантирует доставку персональных сообщений, особенно офлайн; на предоставление доступа это не влияет.

Вопросы: `data/verification_questions.json`. Инструкция по редактированию: `data/README.md`. В комплекте 15 вопросов; варианты ответов перемешиваются, расположение — 2×2. После изменения нужен перезапуск.

## Закреплённое объявление

`/admin` → «📌 Объявление в чат» → чат → текст → подтверждение. Бот публикует текст, закрепляет без уведомления о закрепе, затем открепляет только своё предыдущее объявление, ID которого сохранён в базе. Сам старый текст и другие закрепы не удаляются. Нужны права закрепления. Эта функция отдельна от массовой рассылки.

При ошибке закрепления старый закреп не трогается. При неопределённом ответе Telegram проверьте чат перед повторной публикацией. Незавершённые формы хранятся в памяти и сбрасываются при перезапуске; отправленные жалобы и ID закрепа хранятся в базе.

## Рекламные заявки

Уведомление владельцу содержит кликабельного отправителя с username и ID, выбранное место размещения, описание, ссылку, формат, бюджет и комментарий.

## Покупки

Уведомление владельцу о покупке содержит кликабельное имя через Telegram ID, отдельный кликабельный `@username` при его наличии и кнопку «Открыть покупателя». Если username отсутствует, кнопка использует `tg://user?id=...`, поэтому профиль всё равно можно открыть для выдачи товара или Telegram-подарка.
