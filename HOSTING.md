# Тестовый хостинг ModerBot

## Что загружать

Проект готов к запуску как Docker-сервис. Хостинг должен выполнять `Dockerfile`; миграции базы применяются автоматически перед стартом бота.

## Переменные окружения

Обязательно задайте в панели хостинга:

- `BOT_TOKEN` — токен от BotFather;
- `DATABASE_URL` — строка подключения PostgreSQL вида `postgresql+asyncpg://user:password@host:5432/database`;
- `OWNER_IDS` — Telegram ID владельцев через запятую;
- `PREMIUM_PRICE_STARS=50`;
- `PORT` — обычно хостинг выставляет сам; локально можно использовать `8080`.

Остальные параметры приведены в `.env.example`.

Для однодневного теста без отдельной базы можно временно задать
`DATABASE_URL=sqlite+aiosqlite:///moderbot.db`. Это проще, но после пересборки
или перезапуска бесплатного контейнера настройки и статистика могут исчезнуть.

## Запуск

Docker-команда уже настроена:

```text
python -m alembic upgrade head
python -m app.bot
```

Проверка состояния доступна по `/health`, если задан `PORT`.

## Важно

- Для хостинга используйте PostgreSQL. SQLite-файл на бесплатном хостинге может исчезнуть после перезапуска контейнера.
- Запускайте только один экземпляр polling-бота с одним токеном, иначе Telegram будет отдавать обновления экземплярам вперемешку.
- Добавьте бота администратором в модерируемые группы и в каналы обязательной подписки.
- В BotFather отключите Privacy Mode, иначе бот не увидит обычные сообщения для фильтров и антиспама.
- Никогда не загружайте локальный `.env` и `moderbot.db`; они исключены из Docker-контекста.

## Быстрая проверка после публикации

1. Откройте `/health` — должен вернуться `{"status":"ok","service":"moderbot"}`.
2. Напишите боту `/start`.
3. Проверьте настройки тестовой группы, капчу и обязательную подписку обычным аккаунтом без прав администратора.
4. Для теста PRO используйте тестовую отдельную группу и сохраните квитанцию Telegram Stars.
